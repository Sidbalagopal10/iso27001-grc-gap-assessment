# Northstar Digital Solutions
## Organization Profile

### 1. Company Overview

Organization: Northstar Digital Solutions
Industry: B2B Technology Services
Employees: 50
Operating Model: Hybrid Workforce
Assessment Type: Simulated ISO 27001:2022 Gap Assessment

Northstar Digital Solutions provides cloud-based
technology services and software solutions to
business customers.

The organization relies on cloud infrastructure,
employee endpoints, and SaaS applications to
support daily business operations.

### 2. Technology Environment

Cloud Infrastructure:
- Amazon Web Services (AWS)
- Amazon S3 for data storage
- AWS IAM for identity and access management
- Amazon EC2 for application hosting

Business Applications:
- Microsoft 365
- Microsoft Entra ID
- Email and collaboration platforms

Endpoint Infrastructure:
- Windows employee laptops
- macOS administrator workstations
- Remote employee devices

Security Infrastructure:
- Endpoint antivirus
- Cloud logging capabilities
- Network firewalls
- Centralized security monitoring (partial)

### 3. Information Assets

The organization processes and stores:

- Customer contact information
- Employee personal information
- Financial and billing records
- Application source code
- Cloud configuration data
- Authentication and access records

### 4. Business-Critical Systems

Critical systems include:

- AWS production infrastructure
- Microsoft 365 tenant
- Identity and access management
- Customer data storage
- Business communication services

### 5. Existing Security Challenges

The organization has identified the following
potential security weaknesses:

- Inconsistent MFA enforcement
- Incomplete asset inventory
- Limited security policy documentation
- Inconsistent cloud configuration reviews
- Incomplete incident response procedures
- Limited backup recovery testing

These are fictional preliminary concerns,
not verified audit findings.

### 6. Assessment Objective

Evaluate selected ISO 27001:2022 security
requirements and Annex A controls.

Identify control gaps, evaluate associated
cybersecurity risks, and develop prioritized
remediation recommendations.

### 7. Assessment Limitations

This is a simulated educational assessment.

No production organization is being audited.

Any technical evidence collected from personal
security labs will be labeled separately from
fictional organizational evidence.

This assessment does not establish ISO 27001
certification or full organizational compliance.
