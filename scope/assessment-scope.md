# ISO 27001:2022 Gap Assessment
## Assessment Scope

### 1. Assessment Organization

Northstar Digital Solutions

### 2. Assessment Purpose

Evaluate the current simulated information
security posture against selected ISO 27001:2022
requirements and Annex A controls.

### 3. In-Scope Systems

- AWS IAM
- Amazon S3
- Amazon EC2
- Microsoft 365
- Microsoft Entra ID
- Employee endpoints
- Security logging and monitoring
- Backup and recovery processes
- Incident response procedures

### 4. In-Scope Security Domains

- Information security governance
- Asset management
- Identity and access management
- Cloud security
- Endpoint protection
- Logging and monitoring
- Incident management
- Business continuity and backups

### 5. Out-of-Scope Activities

- Production penetration testing
- Physical data center inspections
- Third-party supplier audits
- Legal certification assessments
- Live exploitation of production systems

### 6. Assessment Methodology

1. Define organizational context.
2. Identify critical information assets.
3. Select applicable ISO 27001 controls.
4. Review simulated or lab-based evidence.
5. Evaluate control implementation.
6. Document security gaps.
7. Assess likelihood and business impact.
8. Prioritize remediation activities.
9. Prepare an executive assessment report.

### 7. Evidence Classification

SIMULATED:
Fictional organizational records created
for the case study.

LAB-VALIDATED:
Sanitized technical evidence obtained from
controlled cybersecurity lab environments.

NOT ASSESSED:
Controls without sufficient evidence.

### 8. Deliverables

- Organization profile
- Assessment scope
- Information asset inventory
- ISO 27001 control assessment matrix
- Cybersecurity risk register
- Remediation roadmap
- Executive assessment report

### 9. Assessment Boundary

This is a selected-control educational gap
assessment, not a complete ISO 27001 ISMS audit.

Formal certification readiness cannot be
established from this assessment alone.
