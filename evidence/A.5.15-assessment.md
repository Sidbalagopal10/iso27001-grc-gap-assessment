# ISO 27001:2022 Control Assessment

## Control Information

Control ID: A.5.15
Control Name: Access control
Organization: Northstar Digital Solutions
Evidence Type: SIMULATED

## Assessment Objective

Evaluate whether access to information and
associated assets is controlled according to
business and information security requirements.

## Simulated Case Assumptions

- Basic access restrictions exist.
- Some user permissions exceed business needs.
- Privileged access is inconsistently reviewed.
- No formal periodic access review records exist.
- Access control rules are not fully documented.

These observations are fictional assumptions.

## Identified Gaps

GAP-007:
Excessive permissions violate least-privilege
principles.

GAP-008:
Periodic user access reviews are not documented.

GAP-009:
Formal access control rules are incomplete.

## Assessment Result

Status: PARTIALLY_MET

Rationale:
Basic access restrictions exist in the fictional
scenario, but least-privilege enforcement and
formal access governance are incomplete.

## Recommended Remediation

1. Establish documented access control rules.
2. Review privileged and standard user permissions.
3. Remove unnecessary permissions.
4. Establish periodic access reviews.
5. Retain access review and approval evidence.

## Evidence Required for Closure

- Approved access control policy
- User and role permission inventory
- Privileged access review records
- Access approval documentation
- Evidence of permission remediation
